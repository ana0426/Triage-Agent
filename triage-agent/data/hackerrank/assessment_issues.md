# HackerRank Assessment Issues

## Assessment Not Loading

If your HackerRank assessment is not loading, try the following steps:
- Clear your browser cache and cookies, then reload the page.
- Use Google Chrome (recommended) or Mozilla Firefox.
- Disable browser extensions, especially ad blockers or privacy tools.
- Ensure JavaScript is enabled.
- Check your internet connection stability.
- If the issue persists within an active test window, contact your recruiter immediately to request a time extension. HackerRank support cannot grant extensions on behalf of recruiters.

## IDE Not Working

HackerRank's online IDE supports multiple programming languages. Common issues:
- If code is not compiling, verify the language version selected matches your code.
- IDE timeout may occur with infinite loops or very heavy computation. Review your algorithm.
- Use the "Run Code" button to test sample cases before clicking "Submit".
- If the IDE is completely unresponsive, try refreshing the page. Your code is auto-saved every 30 seconds.
- Do not use browser back/forward buttons during a test — this can cause data loss.

## Assessment Timer

- The assessment timer runs in real time and cannot be paused by support.
- If you experience a technical failure during the test, document it (screenshot or video) and contact your recruiter immediately.
- HackerRank support does not have the authority to reset or extend individual test timers — only the recruiter/hiring company can do so.

## Test Environment Requirements

Recommended setup:
- Browser: Chrome 90+ or Firefox 88+
- Operating system: Windows 10+, macOS 10.15+, or Ubuntu 18.04+
- Internet: stable broadband (minimum 5 Mbps)
- Screen resolution: 1280×720 or higher
- Webcam and microphone required for proctored assessments
