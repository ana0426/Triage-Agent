# HackerRank Proctoring and Recording

## ProctorTrack

- HackerRank ProctorTrack records webcam video and screen activity during proctored assessments.
- You must grant camera and screen-share permissions before the test starts.
- Supported browsers: Chrome and Firefox. Safari is NOT supported for proctoring.
- Ensure your webcam is functioning and well-lit before beginning.
- Do not use a virtual machine or browser extensions that interfere with screen recording.

## Proctoring Fails to Start

- If proctoring fails to launch, try disabling all browser extensions and restarting the browser.
- Ensure no other application is using the webcam.
- Check that your operating system allows browser access to the camera (System Preferences > Security & Privacy on macOS; Settings > Privacy on Windows).
- Contact your recruiter if proctoring prevents you from starting the assessment — they may be able to configure an alternative.

## Flagged Sessions

- Proctoring flags are reviewed by the recruiting company, not HackerRank.
- Common flags: looking away from the screen, background noise, multiple people detected, tab-switching.
- If you believe a flag is incorrect, contact the hiring company to request a manual proctoring review.

## Privacy During Proctoring

- Proctoring data is shared with the recruiting company and stored as per HackerRank's privacy policy.
- If you have concerns about proctoring, contact the recruiter before starting the test.
