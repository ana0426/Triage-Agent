# Claude Models and Capabilities

## Available Models

- **Claude 3 Haiku**: Fastest and most cost-efficient. Best for simple tasks, classification, and high-volume use cases.
- **Claude 3.5 Sonnet**: Balanced speed and intelligence. Recommended for most tasks including coding, analysis, and writing.
- **Claude 3 Opus**: Most capable for complex reasoning, nuanced analysis, and long-form tasks.
- **Claude 3.5 Haiku**: Improved speed and intelligence over Haiku. Available via API.

## Context Windows

- Claude 3.5 Sonnet: 200,000 tokens context window.
- Claude 3 Opus: 200,000 tokens context window.
- Claude 3 Haiku: 200,000 tokens context window.
- If your conversation exceeds the context window, older messages are truncated. Start a new conversation for fresh context.
- 1 token ≈ 0.75 English words.

## Claude.ai vs API

- Claude.ai is the consumer web interface (chat interface).
- The Anthropic API allows developers to integrate Claude into applications programmatically.
- Claude.ai Pro does not include API credits. API billing is separate.
- API users access Claude via console.anthropic.com.

## Feature Requests

- Claude does not accept feature requests through support tickets. 
- For product feedback or feature suggestions, use the feedback button inside claude.ai or contact feedback@anthropic.com.
- Features like dark mode, conversation search, and custom instructions are planned on the product roadmap but timelines are not guaranteed.
